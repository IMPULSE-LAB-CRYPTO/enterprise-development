# MuseumSystem

Корпоративное приложение для управления музеем на .NET 10.

## Задание

Вариант 20:
- **Доменная область:** Музей
- **База данных:** PostgreSQL
- **Брокер сообщений:** RabbitMQ

### Предметная область

В базе данных музея хранятся сведения об экскурсиях, посетителях и билетах.
- **Экскурсия** характеризуется датой, временем начала, продолжительностью, посещаемыми выставками
- **Выставка** содержит сведения о названии, тематике, номере зала, дате начала и дате окончания
- **Посетитель** характеризуется ФИО, телефоном, датой рождения
- **Билет** содержит информацию об экскурсии и посетителе, тип билета и цену, используется в качестве контракта
